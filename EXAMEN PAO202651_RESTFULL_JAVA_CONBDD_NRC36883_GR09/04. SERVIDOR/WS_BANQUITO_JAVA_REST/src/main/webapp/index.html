Core BanQuito - Módulo de crédito

API Jakarta RESTful Web Services (JAX-RS) que consume la Comercializadora de Teléfonos Celulares.

La raíz de la API es /api. Todas las operaciones envían y reciben JSON.

  • GET /api/credits/eligibility/{cedula}: verificar si una persona es sujeto de crédito.
  • GET /api/credits/max-amount/{codCliente}: obtener el monto máximo de crédito.
  • POST /api/credits: otorgar el crédito y crear la tabla de amortización.
  • GET /api/credits/{codCredito}/amortization: consultar la tabla de amortización.
  • GET /api/credits?cedula={cedula}: listar los créditos de un cliente.

Consulta README.md en el proyecto para ver ejemplos JSON, configuración y códigos de respuesta.
