Comercializadora de Teléfonos Celulares

API Jakarta RESTful Web Services (JAX-RS) de catálogo y facturación. Las ventas con crédito directo invocan los servicios web del Banco BanQuito.

La raíz de la API es /api. Todas las operaciones envían y reciben JSON.

  • GET /api/phones: listar el catálogo (?todos=true incluye los retirados).
  • GET /api/phones/{codCelular}: consultar un celular.
  • POST /api/phones: registrar un celular.
  • PUT /api/phones/{codCelular}: actualizar un celular.
  • DELETE /api/phones/{codCelular}: retirar un celular del catálogo.
  • POST /api/invoices: facturar en efectivo (42% de descuento) o con crédito directo.
  • GET /api/invoices?cedula={cedula}: listar facturas.
  • GET /api/invoices/{codFactura}: consultar una factura.
  • GET /api/credits?cedula={cedula}: listar los créditos del comprador en el banco.
  • GET /api/credits/{codCredito}/amortization: consultar la tabla de amortización.

Consulta README.md en el proyecto para ver ejemplos JSON, configuración y códigos de respuesta.
